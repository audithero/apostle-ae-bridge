About the macOS permission prompt

Rendering HTML sketches to footage uses Chrome on your Mac. On macOS Sonoma and later, you may see a notification saying After Effects "was prevented from modifying apps." This is a standard macOS prompt — nothing is modified, and your render will complete normally.

To dismiss the prompt permanently, grant After Effects App Management permission in System Settings.

Data Collection

Help us improve MotionAmigo by sharing anonymous usage data. We collect:

  • Session timing, panel actions, component usage
  • Tool call names, durations, success/failure
  • Error categories and counts
  • Anonymous machine ID hash

We never collect prompt text, composition names, file paths, or any content you create — nor your IP address, location, or device fingerprint.

Error reports (crash stack traces with paths redacted) are collected separately to fix bugs and aren’t controlled by this toggle.
